# 0004 — Installation : dépôt neuf au palier 1, dépôt existant au palier 3

Date : 19/11/2026 · Statut : accepté

L'installation (`doctor`, découverte, `install`, `verify`, `upgrade`) vise un dépôt neuf au palier 1. L'installation sur un dépôt existant, avec rapport d'aptitude et tests de caractérisation, est spécifiée pour le palier 3 (spec §11).
